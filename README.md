# Wedding Invitation (web)

Vue 3 + Vite invitation site for [GitHub Pages](https://wael-osama-mersvo.github.io/wedding-invitation/).

## Live URL

`https://wael-osama-mersvo.github.io/wedding-invitation/`

Personalized links: `?guest={AES-GCM-token}`

## Local development

```bash
npm install
npm run dev
```

## Deploy

Push to `main` — GitHub Actions builds and deploys Pages automatically.
